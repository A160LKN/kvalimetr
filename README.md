# Квалиметр

Тренажёр для подготовки к экзаменам. Тесты собираются случайно из больших баз сложных вопросов, после теста показывается разбор ошибок, тот же набор можно пройти повторно.

Приложение состоит из одного файла `index.html`. Ему не нужны сервер, сборка, регистрация и внешние зависимости, кроме шрифтов Google Fonts.

## Предметы

| Предмет | Вопросов в базе | Содержание |
|---|---:|---|
| Английский язык | 106 | Грамматика, лексика, понимание текста (вопросы на английском) |
| Аналитическое мышление | 224 | Логика, анализ аргументов, числовые и текстовые задачи, таблицы данных |
| Алгоритмы и структуры данных | 216 | Сложность, сортировки, деревья, кучи, хеширование, графы, ДП |
| Базы данных | 150 | SQL, NULL, JOIN, оконные функции, нормализация, транзакции, индексы |

Есть также **смешанный тест**: по 10 вопросов из каждого предмета с результатом по каждому предмету.

## Как это работает

- **Тест** — 20 случайных вопросов предмета: 75% сложных и 25% средней сложности, простых нет.
- **Разнообразие** — сначала выбираются вопросы, которых пользователь ещё не видел; однотипные задания одного шаблона в один тест не попадают.
- **Перемешивание** — порядок вопросов и вариантов ответа меняется при каждом прохождении.
- **Результат** — итог, число правильных и неправильных ответов, процент и оценка: «Отлично» — от 85%, «Хорошо» — от 70%, «Удовлетворительно» — от 50%.
- **Разбор ошибок** — вопрос, выбранный ответ, правильный ответ и объяснение.
- **Повтор** — тот же набор вопросов в новом порядке и сравнение с прошлой попыткой; можно собрать и новый тест.
- **Хранение** — незавершённый тест и лучший результат сохраняются в `localStorage` браузера. Аккаунтов и синхронизации нет.

## Откуда берутся вопросы

- **Вопросы, написанные вручную**, — массивы `EN`, `AN`, `ALGO`, `DB` в `index.html`. Формат:
  ```js
  ["h" | "m", "Тема", "Текст вопроса", ["верный", "неверный", "неверный", "неверный"], "Объяснение", "R1" /* необязательно: id текста для чтения */]
  ```
  Верный ответ всегда указывается первым, при показе варианты перемешиваются.
- **Сгенерированные вопросы** — массивы `G_AN`, `G_ALGO`, `G_DB`. Каждый шаблон получает случайные параметры и вычисляет правильный ответ кодом: например, трассирует сортировку, обходит граф или выполняет SQL-логику над показанной таблицей. Генератор случайных чисел запускается с фиксированным seed, поэтому база одинакова при каждом запуске, а повторное прохождение получает тот же набор. Каждый шаблон даёт до 8 уникальных вопросов (`PER_GEN`).

### Как добавить вопрос

1. Добавьте строку в нужный массив, соблюдая формат.
2. Проверьте, что все четыре варианта ответа различаются, и напишите объяснение, почему верный вариант верен.
3. Чтобы добавить новый предмет, создайте массивы и запись в `SUBJECTS`, затем добавьте ключ в `ORDER`.

## Запуск

Откройте `index.html` в браузере. Или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.
